# zed.learn

explore [zed](https://zed.dev/docs/)

## on linux

Install with eget but [many ways](https://zed.dev/docs/linux#other-ways-to-install-zed-on-linux)
```bash
eget dariogriffo/zed-debian # select .deb
sudo apt install -y zed*.deb
zed ## starts onboarding
```
Hopefully Ubuntu and Fedora package it soon. 

## on darwin (macosx)

Install `brew install --cask zed`
