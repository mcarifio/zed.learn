# zed.learn

Learn [zed](https://zed.dev/docs/)

## on linux

Install with apt:
```bash
sudo apt install -y zed
zed ## starts onboarding
```

## on darwin (macosx)

Install `brew install --cask zed`

## Initial Quirks
Has an Emacs set of shortcuts. `Ctrl-Y` for `Paste` is missing, use `Shift-Ins` instead. I really should adopt CUA, but 40+ years of emacs will be a difficult habit to break.
